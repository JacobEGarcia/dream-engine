Dream Engine

Prompt-conditioned synthesis of explorable 3D worlds in a single forward pass

J. Garcia1   1Institute of General Acceleration, Chicago

Abstract

We present Dream Engine, a world model that maps free-form natural language directly to a navigable three-dimensional environment. Given a single sentence, the model infers terrain topology, hydrology, vegetation, settlement density, and illumination, then decodes the scene in one pass at interactive frame rates. No precomputed assets are used; every world is sampled from the prompt's latent seed, so the same description always dreams the same world. The system runs entirely in the browser.

Interactive demo

Method

  1. Prompt encoding. The description is hashed into a 32-bit latent seed and scanned for semantic tokens (hydrology, biome, settlement, sky state, palette) that condition the decoder.
  2. Latent terrain. A seeded fractal noise field is sampled over a 128×128 height grid; amplitude and roughness are set by the inferred biome.
  3. Scene decoding. Water, vegetation, rock, and structures are instanced onto the heightfield under the inferred lighting, and the world is streamed to a first-person renderer.

Limitations

Dream Engine is a world model in the literal sense: it models worlds. It has never seen one. Geology is impressionistic, architecture is optimistic, and the model refuses all responsibility for worlds described as “cursed”. Worlds containing two or more moons are decoded at the visitor's own risk.
